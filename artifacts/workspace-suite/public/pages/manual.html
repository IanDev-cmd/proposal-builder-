SETUP

  1. 1

    Run the installer

    Double-click WEOTT-Quote-Builder-Setup.exe in this folder. If Windows SmartScreen appears, choose More info, then Run anyway.

  2. 2

    Let the install finish

    It is one click. There is no folder to choose. It installs for the Windows user who is signed in, and it adds a desktop shortcut and a Start menu shortcut named WEOTT Quote Builder.

  3. 3

    Open the app and wait

    Open WEOTT Quote Builder. Leave the opening card on screen until the progress bar finishes and the card says Ready. The first open starts the proposal engine. On a new computer with internet, saved quotes and proposals are copied onto this PC once.

  4. 4

    Sign in

    Enter the six-digit team PIN. A new install always uses the default below. The session stays in this window and signs out after two hours without mouse or keyboard activity.

  • ✓ Windows 10 or 11, 64-bit
  • ✓ One-click install for this user
  • ✓ Desktop and Start menu shortcuts
  • ✓ Quotes and proposals stay on this PC
